    → Installer : pip install -r requirements.txt

ERREUR : "Données manquantes"
    → Exécuter : python scripts/prepare_bob_with_all_respondents.py

ERREUR : "Port déjà utilisé"
    → Ajouter : --server.port 8502 à la commande
